# Landing Work Branch

## Rama logica

`landing/sections-after-hero`

## Alcance

El Hero queda congelado. Esta rama logica se usa para trabajar unicamente las secciones posteriores de la landing.

## Regla principal

No modificar:

- Navbar
- Hero layout
- Dashboard
- Tipografia base
- Posicion del planeta
- Responsive existente del Hero
